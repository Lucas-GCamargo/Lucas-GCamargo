### 🛡️ [Splunk SOC Analysis](https://github.com/Lucas-GCamargo/Splunk-SOC-Analysis)
*Automated SIEM pipeline · SOC dashboard · Threat detection and alerting*

[![Splunk](https://img.shields.io/badge/Splunk_Enterprise-FF5733?style=flat-square&logo=splunk&logoColor=white)](https://www.splunk.com)
[![Python](https://img.shields.io/badge/Python_3.7+-3776AB?style=flat-square&logo=python&logoColor=white)](https://python.org)
[![Dataset](https://img.shields.io/badge/Dataset-40K_Cyber_Attack_Events-20BEFF?style=flat-square&logo=kaggle&logoColor=white)](https://www.kaggle.com)
[![Status](https://img.shields.io/badge/Status-Completed-2ea44f?style=flat-square)](https://github.com/Lucas-GCamargo/Splunk-SOC-Analysis)

Ingests 40,000 synthetic cyber-attack events into Splunk Enterprise and analyses them across a 3-panel SOC dashboard — covering firewall audit, attack trend timelines, and anomaly events ranked by severity score.

**Key finding:** Analysis revealed a critical firewall misconfiguration — high-severity attacks were being **ignored instead of blocked** — a gap that was completely invisible without systematic log querying.

**Technical highlights:**
- SOC-style SPL queries covering aggregation, time-series analysis, anomaly detection, and automated alerting
- Python HEC ingestion prototype with SHA-256 deduplication and crash-recovery state persistence
- Alert threshold logic triggering on sustained high-severity event spikes

### 🔐 [Cybersecurity Password Audit Tool](https://github.com/Lucas-GCamargo/Cybersecurity-Password-Audit)
*Credential auditing · Dictionary attack simulation · Security-safe output*

[![Python](https://img.shields.io/badge/Python_3-3776AB?style=flat-square&logo=python&logoColor=white)](https://python.org)
[![OWASP](https://img.shields.io/badge/Standard-OWASP_%2B_NIST_800--63B-DC143C?style=flat-square)](https://owasp.org)
[![Algorithm](https://img.shields.io/badge/Algorithm-SHA--256-FF8C00?style=flat-square)](https://en.wikipedia.org/wiki/SHA-2)
[![Status](https://img.shields.io/badge/Status-Completed-2ea44f?style=flat-square)](https://github.com/Lucas-GCamargo/Cybersecurity-Password-Audit)

Identifies weak password hashes within a credential database using wordlist-based dictionary attack simulation — replicating the defensive audit workflow security teams use to detect at-risk accounts before attackers do.

**Technical highlights:**
- Pre-computed hash dictionary for **O(1) lookups** at scale — versus O(n×m) for naive linear comparison
- Security-safe output: no plaintext passwords stored — reports hash, cracked status, and risk category only
- Aligned with OWASP and NIST SP 800-63B password security guidelines
